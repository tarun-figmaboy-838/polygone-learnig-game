# Voice-over script — Swiftee & the Polygons

Every line Swiftee says, in the order the game says them, with the id of its
clip. Drop a clip at `assets/vo/<id>.mp3` and the game plays it as the words
appear; a clip that is not there is simply silent, so they can be added a few
at a time.

**Voice:** Swiftee — a small, warm, playful teal bird talking to a seven-year-old.
Clear, unhurried, smiling; never shouty. Lines end with a smile, not a drop.

**Files:** mono MP3, 44.1 kHz, 128 kbps or better, loudness about −16 LUFS,
no silence longer than 0.2 s at either end. Keep each clip close to the reading
time of its words (roughly 0.4 s per word plus 0.4 s).

**Lines marked "two bubbles":** the line is two sentences, and the game shows
them in two speech bubbles in turn. Record it as one clip, read naturally, with
a short pause between the sentences.

## Adding clips

Put the files in `assets/vo/` and run `npm run build:vo`. That writes
`assets/vo/index.json`, the list of clips the game may ask for; a clip that
is not listed is never requested, so there is no error for a line that has
no recording yet.

### From one long take

`npm run split:vo` cuts a single recording (`src/audio/voices.mp3` by
default) at the gaps between lines, writes the pieces to `assets/vo/take/`
and lists them in `assets/vo/take/mapping.json` with an empty `id` on each
row. Fill in the id for each piece from the tables above — the take that was
recorded holds 37 runs of speech and this script has 59 lines, so which piece
is which line is a decision, not something the cutter can know — then:

```
node tools/split-vo.js --apply
```

which copies each named piece to `assets/vo/<id>.mp3` and rebuilds the index.
The raw take and its pieces stay out of the repo; only the named clips ship.

## How it is wired

- `src/audio/vo.js` — `VO.play(id)` plays `assets/vo/<id>.mp3` if the id is in `assets/vo/index.json`; one clip at a time; muted with the game.
- The say handler in `src/game/game.js` calls it for any line carrying a `vo`; `react()` calls it for feedback.
- Ids live in `src/game/screens.js` (`vo:` on the say and instruction beats) and in the PRAISE/NUDGE tables in game.js.
